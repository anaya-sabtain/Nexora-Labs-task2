# Nexora Labs

A responsive business website and authentication dashboard interface
built using HTML, CSS, and Bootstrap.

## Project Overview

Nexora Labs is a modern responsive frontend project designed to
demonstrate a professional authentication and dashboard experience.

## Features

- Responsive homepage
- Login page
- Signup page
- Client-side form validation
- Password visibility toggle
- Responsive dashboard
- Dashboard sidebar
- Statistics cards
- Recent projects
- Recent activity
- Responsive mobile navigation

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript

## Responsive Design

The interface is designed for:

- Desktop
- Laptop
- Tablet
- Mobile
